\# work\_\_app（LINEミニアプリ勤怠管理システム）



LINEミニアプリ上で動作する、シンプルな勤怠管理Webアプリケーションです。



\## 主な機能（予定・実装中）

\- \[ ] LINEミニアプリからの起動・ユーザー認証（LIFF）

\- \[ ] 出勤・退勤の打刻機能

\- \[ ] 勤怠履歴の一覧表示



\## 使用技術・開発ツール

\* \*\*バックエンド:\*\* Python / Flask

\* \*\*テンプレートエンジン:\*\* Jinja2

\* \*\*プラットフォーム:\*\* LINEミニアプリ (LIFF)

\* \*\*開発環境・ツール:\*\* VS Code / ngrok（ローカルサーバーの外部公開用） / Git / GitHub
